# docs/reference — 외부 자료·컨벤션 보관

프로젝트 바깥에서 온 **가이드·규약·발췌 자료**. 읽기 전용 참조.

## 현재 내용물

| 문서 | 설명 |
|---|---|
| `UE5-GAS-Naming-Convention.md` | UE5+GAS 네이밍 컨벤션 (에셋 접두사 / C++ 클래스 / GameplayTag 계층) |

> ⚠️ **네이밍 규약과 실제 코드가 어긋나 있다** (2026-08-24 실측).
> 문서는 `U{ProjectPrefix}{ClassName}`(예 `UKDCombatAttributeSet`)을 규정하지만,
> 실제 C++ 클래스 93개는 **접두 없음 43 / 타입 접두(`AS_` `GA_` `GE_` `ANS_` `GCN_`) 35 / `KD` 접두 15** 로 쓰인다.
> 예: 실제는 `UAS_Combat` · `UGA_Dodge` · `AKDPlayerCharacter`.
> → 코드 93개를 개명하는 건 비현실적이므로 **문서를 현실에 맞추는 개정**이 필요하다. 보류 중.

## 예시 (여기 둘 만한 것)

- UE5 / GAS 공식 문서 발췌
- 외부 강의·아티클에서 가져온 규약 정리
- 엔진 API 레퍼런스 스냅샷

## 룰

- 라이선스·저작권 명시 (외부 자료는 출처 표기)
- 대용량(>10MB) 바이너리는 저장소에 두지 않는다 — git 저장소 비대 방지
- **프로젝트 내부 문서는 여기가 아니다.** 시스템 설계 → `docs/design/`, 마일스톤 스펙 → `docs/specs/`, 개발 기록 → `docs/dev-logs/`
