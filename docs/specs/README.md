# docs/specs — 마일스톤 답안지

페어가 작성하는 **현재 마일스톤의 검증 기준**. CLAUDE.md §0 / §4 참조.

## 파일 명명
- `M1-spec.md`, `M2-spec.md`, ...
- 또는 의미 있는 이름: `M1-combat-core-spec.md`

## 권장 섹션
```
## 목표 (한 줄)
## 결정사항       — 페어 합의된 아키텍처 / 수치 / 모드 선택
## 작업 항목       — 분담 + 예상 시간
## 검증 항목       — 마일스톤 종료 게이트 체크리스트
## 위험            — 알려진 함정 / 미결 사항
```

## 룰
- 결정사항 임의 변경 금지 — 변경 시 페어 confirm → patch → 진행
- 마일스톤 검증 항목 ✓ 안 되면 다음 마일스톤 진입 금지
