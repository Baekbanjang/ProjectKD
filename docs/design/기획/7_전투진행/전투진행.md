# 🎯 전투진행 기획

> 영역 책임: 승환 / **데모 결정 완료 (deep-interview 4 Round)**

---

## ✅ 핵심 결정 (P2 표준 + 적 등급 차등)

### 사망·리스폰·체크포인트 (G3.3·G3.4)

| 항목 | 결정값 |
|------|--------|
| **사망 조건** | HP 0 = **즉사** (유예 없음) |
| **리스폰** | 마지막 체크포인트 |
| **페널티** | **없음** (체크포인트 빈도가 페널티 대체) |
| **체크포인트 수** | **5개** |
| **체크포인트 위치** | 구간1·2·3·4 진입 시 4개 + 보스 페이즈 사이 보너스 1개 |

### 보스전 흐름

| 항목 | 결정값 |
|------|--------|
| **페이즈 전환 트리거** | HP% (100→70→40%) — Epic A3.6 BTService |
| **광폭화 발동 (D5)** | **보스 페이즈 3 진입 시 자동** (HP 40% = 페이즈 3 트리거, 본질은 "페이즈 3 진입 = 광폭화") |
| **광폭화 지속 (D12)** | **보스 처치까지** (페이즈 3 = 광폭화 그 자체) |
| **광폭화 효과** | 보스 동작 0.4배속, 길동 Stamina·Doul 무제한, 콤보 캔슬 윈도우 풀 오픈 |

### 전투 외 흐름 (Standard 패턴)

| 항목 | 결정값 |
|------|--------|
| **전투 시작** | 적 시야 진입 + 근접 (UE AIPerception 표준) |
| **전투 종료** | 해당 구역 적 전멸 |
| **Stamina 회복** | 전투 중 시간 회복 (회피·강공 사용 시 소모) |
| **Doul 회복 (D1)** | **콤보 적중 + 패링 누적** (시간 회복 X) |
| **HUD 전환** | 전투·탐험 상시 동일 (3바 좌상단·도술 슬롯 우하단) |

## ✅ Success Criteria (데모 단계)

| ID | 기준 | 측정법 |
|----|------|--------|
| **MIN-1** | 개발 빌드에서 5구간 모두 통과 가능 | 빌드 수동 검증 |
| **MIN-2** | 보스전 페이즈 3 진입 시 광폭화 100% 자동 발동 | 보스전 5회 검증 |
| **MIN-3** | 5개 체크포인트 모두 정상 작동 (사망 → 리스폰) | 각 위치 의도적 사망 + 리스폰 검증 |

> ⚠️ 페어 관찰 기반 측정 (클리어 시간·사망 횟수)은 4_밸런싱 영역 / 본편 잡몹 도주는 본편 단계.
