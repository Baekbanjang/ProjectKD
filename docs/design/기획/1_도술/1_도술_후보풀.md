## 📚 카테고리별 후보 카탈로그

### 🔥 5행 부적술 (S1 콤보 보조 / 광역 슬롯 계열)

| 도술 | 한자 | 효과 | 시각 |
|------|------|------|------|
| **화부술** ✅ | 火符術 | 불기둥 광역 + 화상 도트 | 황금 부적 → 불기둥 |
| 수부술 | 水符術 | 적 발밑 물웅덩이 → 미끄러짐·이동 봉인 | 푸른 부적 → 물 |
| 목부술 | 木符術 | 가시·덩굴 솟구침 → 발 묶기 + 도트 | 녹색 부적 → 덩굴 |
| 금부술 | 金符術 | 칼날 다수 발사 → 다단 히트 | 은빛 부적 → 금속 칼날 |
| 토부술 | 土符術 | 땅 융기 → 적 띄우기 (공중QTE 시너지) | 갈색 부적 → 융기 |

> 📈 본편 확장 카탈로그. 데모는 화부술 1종만.

### 🌬 보법 (S2 이동 슬롯 계열)

| 도술 | 한자 | 효과 | 모티프 |
|------|------|------|--------|
| **풍보** ✅ | 風步 | 바람타고 도약·활공 | 호풍환우·신선 |
| 화보 | 火步 | 불꽃 도약 — 도착 시 폭발 데미지 | 불 |
| 수보 | 水步 | 물 위 보행 (환경 활용) | 물 |
| 그림자 도약 | — | 적 그림자 ↔ 본인 그림자 순간 스왑 | 그림자 |
| 분신 잔상 (회피) | — | 회피 시 분신 1개 남김 → 적 어그로 | 분신 변형 |
| 벽 보법 | — | 벽·환경 타고 짧게 이동 | Sekiro·명조 |
| 시간 정지 보법 | — | 본인 0.5s 시간 정지 → 자유 이동 | 시간 도술 |
| 봉 던지기 텔레포트 | — | 봉 던진 자리로 순간 이동 | Thor식 |

### ⚡ 자연·뇌격 도술

| 도술 | 효과 | 비고 |
|------|------|------|
| 뇌격술 (雷擊術) | 봉 끝 번개 응축 → 광역 감전 + 도트 | 호풍환우 연속 |
| 호풍환우 — 강풍 | 회오리 → 적 광역 밀어내기 | 풍보 충돌 |
| 호풍환우 — 폭풍우 | 비 + 바람 → 시야 차단 + 슬로우 | 환경 효과 |
| 호풍환우 — 천둥 | 하늘 번개 1발 → 광역 즉발 | 강력함 |

### 🌑 음양·결계·그림자

| 도술 | 효과 |
|------|------|
| 음양 결계 | 발밑 원형 결계 → 진입 시 경직·슬로우 |
| 그림자 매듭 | 적 그림자 묶기 → 이동 봉인 |
| 북두칠성 진법 | 7별빛 시간차 낙하 → 광역 |
| 부적 도배 | 다수 부적 부착 → 지연 일제 폭발 |

### 🐯 변신·소환·환영

| 도술 | 효과 | 상태 |
|------|------|------|
| 둔갑술 (적 변신) | 적을 닭/돼지로 변환 | ❌ 거부 (간접) |
| 활빈당 소환 | 빈민 NPC 떼 등장해 적 매질 | ❌ 거부 (타인) |
| 둔갑술 (본인 짐승화) | 길동이 호랑이/곰으로 변신 → 일격 | 🟡 보류 |
| 둔갑장신 | 잠시 투명화 + 다음 약공 강화 | 🟡 보류 |
| 귀신 소환 | 도깨비 1마리 옆에 → 타격 | 🟡 보류 |
| 봉 분열 | 봉 던지면 다수 분열 → 자동 다단 타격 | 🟡 보류 (분신과 유사) |

### 🥢 봉 도술 변형

| 도술 | 효과 | 상태 |
|------|------|------|
| 봉 거대화 | 도력 주입 → 봉 3~5배 늘림 → 광역 후려치기 | 🟡 보류 |
| 도력 봉구체 | 봉 끝 도력 응축 → 발사·폭발 | 🟡 보류 |
| 강풍 봉술 | 봉 회전 → 회오리 (호풍환우와 통합) | 🟡 보류 |

### 📢 음파·외침

| 도술 | 효과 | 상태 |
|------|------|------|
| 사자후 / 호통 | 음파 광역 경직 + 약공 | ❌ 거부 (유사 시스템 존재) |
| 정승 포효 | 정승 입에서 황금 음파 | ✅ S3 정승 스턴에 통합 |
