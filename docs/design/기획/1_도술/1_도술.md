## 🔄 재설계 배경 (2026-05-14)

기존 도술 3종 (분신·축지·스턴) 중 **분신·축지는 진부 + 홍길동 정체성 약함** 판단으로 **완전 폐기**.
스턴(정승)은 컨셉 살리고 유지. 새 도술 2종 = **화부술 + 풍보** 1차 확정.

| 결정 축 | 결정값 |
|---------|--------|
| **역할 위치** | 도술 = **보조·전술 위주** (공격 = 봉 콤보 + 동에번쩍 QTE 담당) |
| **레퍼런스** | 검은 신화: 오공 스킬 구조 (보조 + 빌드 확장) |
| **데모 범위** | 도술 3종 보여주기. 빌드/강화 시스템은 본편 예고만 |
| **본편 확장** | 5행 도술 체계 (화·수·목·금·토) — 부적·보법 시리즈로 확장 |

## ✅ 1차 확정 — 도술 3종

| 슬롯 | 키 | 도술 | 한자 | 역할 |
|------|----|------|------|------|
| S1 | `1` | **화부술** | 火符術 | 콤보 보조 / 광역 |
| S2 | `2` | **풍보** | 風步 | 이동 / 접근 / 회피 |
| S3 | `3` | **정승 스턴** | — | 컨트롤 / 광역 경직 |

### 🎴 S1. 화부술 (火符術) — 1키 ✅ 메커니즘 1차 확정

| 항목         | 결정값                             |
| ---------- | ------------------------------- |
| **컨셉**     | 부적 던져 불기둥 발생. 무속+도술 모티프         |
| **발동 모드**  | 락온 우선 + 자동 폴백 (MMB 조준 K-B와 연계)  |
| **광역 패턴**  | 다발 (3~5장 부적) — 작은 불기둥 여러 개 흩뿌림  |
| **데미지 분포** | 즉발 큰 데미지 (광역 + 한방형)             |
| **시각**     | 황금 부적 흩뿌려짐 → 동시 폭발로 불기둥 솟구침     |
| **본편 확장**  | 수부 / 목부 / 금부 / 토부 (5행 부적 시리즈)   |
| **밸런싱 미정** | 부적당 데미지·범위·쿨다운·Doul 소모량 → 4_밸런싱 |

### 🌬 S2. 풍보 (風步) — 2키 ✅ 메커니즘 1차 확정

| 항목           | 결정값                                         |
| ------------ | ------------------------------------------- |
| **컨셉**       | 바람타고 활공. 호풍환우 변형 + 신선·신출귀몰 모티프              |
| **입력 방식**    | 단발 탭 (D4 해소)                                |
| **방향**       | 자동 — 락온된 적 방향 우선, 없으면 카메라 정면                |
| **공중QTE 연결** | ❌ 없음 — 풍보는 순수 이동·접근 도구. QTE는 적 부양 시에만 별도 발동 |
| **본편 확장**    | 화보 / 수보 등 5행 보법, 재도약 노드                     |
| **밸런싱 미정**   | 활공 거리 미세 조정·쿨다운·Doul 소모량 → 4_밸런싱            |

#### 🎬 5단계 시퀀스 (총 ~0.85초)

| 단계 | 시간 | 동작 | 시각 |
|------|------|------|------|
| **1. 차지** | 0.1s | 길동 살짝 무릎 굽힘 + 발밑 바람 회오리 응축 | 황금 도력 회오리 응축 |
| **2. 점프** | 0.2s | **3~4m 수직 솟구침** (제자리) | 발밑 흙먼지·낙엽 흩어짐 |
| **3. 공중 정지** ⭐ | 0.15s | **공중 1프레임 정지 + 약 슬로우모** — 시그니처 모먼트 | 카메라 살짝 줌 + 락온 적 락 확정 |
| **4. 돌진** | 0.3s | 락온 적 쪽으로 **빠른 활공 5~8m** | 길동 잔상 1개 + 바람 띠 |
| **5. 착지** | 0.1s | **적 옆/뒤 자연 착지** (거리 기반) | 착지 흙먼지·낙엽 |

#### 🎯 도착 위치 (단계 5)
- **거리 기반 자연 도착**: 적 멀면 옆 / 가까우면 지나쳐 등 뒤
- 적 락온 없으면 → 카메라 정면 5~8m 활공 (순수 이동)

### 🪨 S3. 정승 스턴 — 3키 ✅ 메커니즘 1차 확정

| 항목           | 결정값                                              |
| ------------ | ------------------------------------------------ |
| **컨셉**       | 길동 양옆 땅에서 정승 2기 솟구침 → 전방 황금 음파 포효                |
| **정승 위치**    | 길동 양옆 (좌·우 고정)                                   |
| **포효 방향·범위** | 전방 부채꼴 — 약 110도, 거리 10m                          |
| **효과**       | 약한 데미지 + **긴 스턴 (2~3초)** — 컨트롤형                  |
| **정승 후속 동작** | 즉발 1회 포효 → 정승 N초 동안 서 있음 → 다시 땅으로 침수             |
| **시각**       | 정승 솟구침 → 입 벌려 황금 음파 폭발 → 정승 정지 → 침수              |
| **사운드**      | 솟구침 음 + 입 벌리는 국악 톤 + 적 스턴 임팩트                    |
| **밸런싱 미정**   | 정승 서있는 시간 (예: 3초)·쿨다운·Doul 소모량·동시 영향 적 수 → 4_밸런싱 |
