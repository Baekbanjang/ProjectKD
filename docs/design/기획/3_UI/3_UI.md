### 🎯 U-5. Stagger / Posture 시스템

> **용어 정의**
> - **Posture** = 게이지 (감소 가능한 수치)
> - **Stagger** = 상태 (Posture 0 도달 시 진입하는 경직 상태)

| 항목 | 결정값 |
|------|--------|
| **발동 조건** | Posture 게이지 **완전 소진 (0 도달)** → Stagger 상태 진입 → 공중QTE T1 트리거 |
| **게이지 형태** | C — 노란 외곽선 (검은 신화: 오공 스타일) |
| **색 처리** | B — 단색 + 소진 시 깜빡임 |
| **표시 — 잡몹** | ❌ Posture 게이지 UI 없음 (적 머리 위 HP 바만). Stagger 0 도달 시 **[F] 처형 키 프롬프트** 표시 |
| **표시 — 엘리트** | 적 머리 위 HP 바 **바로 아래** Posture 게이지 |
| **표시 — 보스** | HUD **하단** (보스 HP 3분할 바 인접 — 검은 신화 오공 스타일) |
| **발동 가능 시 이펙트** | 게이지 색 외에 **적 본체에 이펙트 추가** (예: 황금 균열 + 발톱 표식) → 공중QTE 1단계 페이탈 표시와 연동 |

> 🔗 공중QTE T1 트리거 = Posture 0 도달. 상세는 [[기획/5_공중QTE/5_공중QTE]] 참조.
