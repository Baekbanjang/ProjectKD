# HUD 시방서 — 흑길동 데모

---

## 1. 프로젝트 컨텍스트 요약

**흑길동**은 조선 무협 배경의 25분 분량 UE5.6 + GAS 데모. 주인공은 흑인 혼혈 도술사 길동이며 봉술 + 3종 도술(분신·축지·스턴) + 공중QTE(동에번쩍)가 핵심 메커니즘. HUD 방침은 **극단 미니멀** — 숫자 없이 바만, 초상화 없음, 미니맵 없음. 레퍼런스는 Stellar Blade(좌측 바 레이아웃) + Black Myth: Wukong(쿨다운 외곽선 차오름·Posture 게이지).

## 4. 위젯별 시방서

### 4-1. WBP_HUD — 좌상단 3바 (HP / Stamina / Doul)

**위치·크기**

| 항목 | 값 |
|------|-----|
| Anchor | 좌상단 (0.0, 0.0) |
| Offset (X, Y) | +24px, +24px (화면 좌상단에서) |
| 바 너비 | 화면 너비의 18% |
| 바 높이 | 8px (HP) / 6px (Stamina) / 6px (Doul) |
| 바 간격 | 6px |
| 수직 배치 순서 | HP → Stamina → Doul (위→아래) |

**상태별 변화**

| 상태 | HP 바 | Stamina 바 | Doul 바 |
|------|--------|------------|---------|
| Idle (100%) | 황토 `#C07D3A` 꽉 참 | 이끼 `#4A6741` 꽉 참 | 솔잎 `#2D4A2A` 꽉 참 |
| 감소 중 | 우측에 흙먼지 `#8B7355` Drain 잔상 1.2s 지연 후 수축 | 즉시 수축 (Stamina는 빠른 반응 필요) | 즉시 수축 |
| 위험 (≤20%) | `#8B2020` 로 색 전환 + 0.8s 주기 깜빡임 | — | — |
| 회복 중 | 좌→우 채워짐, ease-out | 좌→우 채워짐, linear | 좌→우 채워짐, ease-in-out |
| 0 (사망/고갈) | 완전 비워짐 + 깜빡임 정지 | 완전 비워짐 | 완전 비워짐 |

**애니메이션**

| 이벤트 | 애니메이션 |
|--------|-----------|
| 피격 시 HP 감소 | Drain 잔상 색(`#8B7355`)이 먼저 남고, 1.2s 후 ease-out으로 수축 |
| HP 임계(≤20%) | `UMG_WidgetAnimation` 깜빡임, 0.8s 주기, Opacity 1.0 ↔ 0.4 |
| 바 등장 (게임 시작) | 좌측에서 슬라이드인, 0.4s ease-out |
| 도력 소모 | 우측부터 즉시 수축, ease-in 0.15s |

**폰트·스타일**

- 바 위 레이블 없음 (숫자 표시 금지 — U-1 정책)
- 바 좌측에 소형 한자 아이콘 (기(氣)·기(氣)·도(道)) 8×8px, 불투명도 60% — 색맹 대비용 최소 힌트

| 상태 | HP 바 | Posture 바 |

### 4-5. WBP_BossHP — 보스 HP 3분할 바 + 보스 Posture (하단 중앙)

**위치·크기**

| 항목 | 값 |
|------|-----|

| Posture 바 너비 | HP 바와 동일 |
| Posture 바 높이 | 6px |
| HP-Posture 간격 | 5px |

**3분할 구조**

```
[페이즈1 영역 ────────────|페이즈2 영역 ────────────|페이즈3 영역 ────────────]
                          ▲ 분할선(2px, 황금)          ▲ 분할선(2px, 황금)
```

- 페이즈 전환 시: 분할선 좌측 영역 drain 후 중앙 flash + 짧은 셰이크 (0.3s)
- 페이즈 3 진입 시: HP 바 전체 황토 → 위험 빨강 `#8B2020` 전환 (광폭화 연동)

**보스 Posture 바 (하단 배치 — Black Myth: Wukong 스타일)**

| 상태 | 시각 |
|------|------|
| 기본 | 황금 외곽선 `#E8C547`, 단색 황금 채움 |
| 소진 임박 (≤20%) | 0.4s 주기 깜빡임 |
| = 0 (Stagger) | 전체 flash 0.5s (황금→흰색→소멸) → 공중QTE 1단계 이펙트 트리거 |
| Stagger 회복 중 | Posture 바 빠르게 우측부터 채워짐 (Stagger Recovery 타이머 연동) |

**등장·퇴장**

| 이벤트 | 애니메이션 |
|--------|-----------|
| 보스 조우 (첫 피격·컷씬 전환) | 하단에서 슬라이드업 0.5s ease-out |
| 보스 처치 | FadeOut 1.0s |

**보스 이름 라벨**

- HP 바 좌측 위 8px 위치
- 텍스트: 보스 이름 (예: "도적 두목")
- 폰트: 12px, 자막 흰색 `#F0EAD6`, 불투명도 80%
- 숫자 수치 없음 (U-1 정책)

### 4-6. WBP_QTE — 공중QTE 프롬프트 (화면 중앙)

> GameplayMessage(GC) 수신 → WBP_QTE Visible. 조건 해제 시 Hidden.

**위치·크기**

| 항목 | 값 |
|------|-----|
| Anchor | 중앙 (0.5, 0.5) |
| Offset | 0, -60px (화면 정중앙 약간 위) |
| 프롬프트 박스 크기 | 200×56px |

**6단계 시퀀스별 HUD 변화**

| 단계 | HUD 상태 |
|------|----------|
| **1단계 — 페이탈 가능 표시** | 적 머리 위 Posture 바 flash (황금→흰색) + 적 본체 황금 균열 GameplayCue 재생 + 화면 중앙 `[F] 동에번쩍` 프롬프트 FadeIn 0.3s |
| **2단계 — 강공 띄움 (T1만)** | 프롬프트 유지, 입력 링 0.8s 카운트다운 시작 (황금 외곽선 시계방향 감소) |
| **3단계 — 점프 추격** | 프롬프트 FadeOut 0.2s, 슬로우모 진입 (0.2x), 화면 채도 약간 감소 |
| **4단계 — 공중 연타 Phase 1** | 화면 중앙 R 버튼 아이콘 + `연타 x5` 텍스트 표시, 콤보 카운터 `x18` 우상단 표시 |
| **5단계 — 3타 마무리 Phase 2** | 화면 중앙 `[3타 마무리] FINISH` 텍스트, 슬로우모 강화 + 카메라 셰이크 |
| **6단계 — 지면 내리꽂기** | 적 머리 위 `Stagger Recovery 2.0s` 카운트다운 텍스트 표시 + 전체 HUD 복구 |

**QTE 프롬프트 스타일**

| 요소 | 스타일 |
|------|--------|
| 배경 박스 | 먹 `#1A1410` 반투명 (Alpha 70%), 모서리 radius 4px |
| 키 아이콘 `[R]` | 황금 `#E8C547` 테두리 원, 내부 텍스트 흰색 30px |
| 텍스트 | `동에번쩍`, 자막 흰색 `#F0EAD6`, 18px |
| 입력 윈도우 링 | 황금 `#E8C547` 원형 외곽선, 0.8s 시계방향 감소 |
| 실패 시 | 빨강 flash 0.3s + FadeOut |

**콤보 카운터 (4단계)**

| 항목 | 값 |
