## 🎯 핵심 인사이트 (배운 것 — 가장 중요)

### 1. **단순 액션은 짧을수록 깔끔**
- 5초 강제 시 AI가 빈 시간을 "마을 탐험·카메라 회전"으로 채움
- 자연스러운 액션 길이 (2~3초) = 영상 길이로 매칭 권장

### 2. **이펙트는 적을수록 좋음**
- "hit-stop·screen shake·dust burst·flash·speed lines" 다 명시 → AI가 모두 시도 → 모래 폭풍 발생
- 핵심 효과 1~2개만 (slow-motion + small dust puff) → 깔끔한 결과

### 3. **카메라 락은 명시적 부정 필요**
- "OTS gameplay camera"만 명시 → AI가 시작 위치로만 해석, 중간 회전 OK
- "❌ NO rotation, NO orbit, NO front view" 명시 부정 → 강제 락

### 4. **액션 비유가 강력**
- "swing staff downward" = 추상적
- **"like swinging a sledgehammer or splitting wood with an axe"** = AI 즉시 이해
- 익숙한 일상 모션 비유 → 정확한 결과

### 5. **REAL-TIME IN-GAME 명시 = 영화 모드 차단**
- 명시 없으면 AI가 "cinematic film" 모드로 해석 → 영화 영상 됨
- "REAL-TIME IN-GAME GAMEPLAY FOOTAGE" 첫 줄에 강조 → 게임 화면 톤

### 6. **HUD 명시 = 인게임 느낌의 핵심**
- HUD 안 보이면 영화 컷 → 게임 영상 아님
- 4가지 HUD 위치 명시 (portrait·boss HP·doulsul slots·inventory)

### 7. **Start-End 모드는 보간 안정성 ↑**
- 다중 레퍼런스 모드 = 이미지를 "분위기"로만 해석 → 시작 프레임 안 맞음
- Start-End 모드 = 정확한 시작·끝 프레임 보장

## 📝 최종 작동 프롬프트 (재사용 가능 템플릿)

### 공중 QTE 지면 내리꽂기 (3초)

**입력 자료**:
- Start: `자료/C5_3타마무리.png`
- End:   `자료/C6_지면내리꽂기.png`

**프롬프트**:
```
3초: REAL-TIME IN-GAME GAMEPLAY FOOTAGE.

The MAIN ACTION is a single powerful DOWNWARD STAFF SWING — like 
swinging a sledgehammer or splitting wood with an axe.

ACTION SEQUENCE (3 beats):

Beat 1 (0~0.8s): The warrior holds his wooden staff overhead with 
both hands, ready to strike. (matches start frame)

Beat 2 (0.8~1.5s): The warrior SWINGS THE STAFF DOWNWARD with full 
force — a single decisive arc. Brief slow-motion at the moment the 
staff connects with the enemy below.

Beat 3 (1.5~3s): The enemy is PROPELLED downward by the staff strike, 
crashing head-first into the ground. The warrior's body naturally 
follows through the swing motion, landing in a final pose looking 
down at the impacted enemy. (matches end frame)

⚠️ CRITICAL: The STAFF SWING is the action — NOT a body slam, NOT a 
dive. The warrior swings the staff like an axe; his body moves only 
as natural follow-through to the swing. The enemy is what gets 
launched downward by the staff strike.

CAMERA: Static behind the warrior's shoulder. NO movement, NO rotation.

EFFECTS — minimal:
- Small dust puff when enemy hits ground
- ❌ NO sandstorm, NO flash, NO speed lines, NO screen shake

HUD visible (top-left portrait + bars / bottom-center boss HP "산적 두목" 
/ bottom-right slots [1][2][3] + Shift / bottom-left [4][5])

ART STYLE: Stellar Blade gameplay style.
```

## 📊 프롬프트 진화 과정 (시행착오 기록)

| 버전 | 시도 | 문제 | 배운 점 |
|------|------|------|--------|
| v1 | 단순 액션 묘사 | 영화 영상 느낌, 임팩트 부족, 시점 어긋남 | 명시 부정 + 인게임 강조 필요 |
| v2 | + IMPACT EFFECTS 6가지 + REAL-TIME 명시 + OTS 강조 | 모래 폭풍 발생 (이펙트 너무 많음) | 이펙트는 적을수록 좋음 |
| v3 | 이펙트 미니멀 + ❌ NO 8가지 명시 | 길동·적이 같이 추락 (액션 잘못 해석) | 액션 의도 명시 강화 필요 |
| v4 | "@길동 ABOVE enemy", "swing DOWNWARD" 강조 | 카메라 회전, 마을 탐험 발생 (5초가 너무 길었음) | 길이 줄이기 + 카메라 락 강화 |
| v5 ⭐ | 3초 + 카메라 락 + Start-End 모드 + "sledgehammer/axe" 비유 | ✅ 의도대로 작동 | 단순 액션 = 짧게 + 익숙한 비유 |

## 💡 사용 팁 모음

### 프롬프트 작성
- **첫 줄에 "REAL-TIME IN-GAME GAMEPLAY FOOTAGE"** 강조 → 영화 모드 차단
- **MAIN ACTION 비유** (sledgehammer·axe·swat 등) → AI 즉시 이해
- **3 beats 구조** (준비 → 액션 → 결과) → 자연스러운 시간 분배
- **❌ NO 명시** = AI 본능 차단의 핵심

### 이미지 활용
- **Start-End Frame 모드** > 다중 레퍼런스 모드 (시작·끝 보장)
- 시작·끝 이미지가 액션 의도와 정합해야 함 (안 맞으면 AI가 자기 식대로 보간)

### 설정
- **720p + 사운드 OFF** = 크레딧 33% 절약, 결과 품질 차이 작음
- **스마트 멀티 샷 OFF** (단일 액션일 때) → 카메라 회전 방지
- **3~5초** = 단순 액션. 길수록 AI가 임의 콘텐츠 채움

### 결과 평가
- 1번에 완벽 X — 평균 2~3회 재시도 필요
- 캡처 3~5장 (시작·중간·임팩트·끝) 분석 = 가장 빠른 진단
- 안 맞는 부분만 프롬프트 핀포인트 수정

## 🚨 트러블슈팅 표

| 증상 | 원인 | 해결 |
|------|------|------|
| 영화 영상 느낌 | "cinematic" 등 단어 영향 | "REAL-TIME IN-GAME" 첫 줄 + "NOT cinematic film" 명시 |
| 카메라 회전·정면 컷 | OTS 락 약함 + 5초 너무 김 | "FIXED, NO rotation" + 길이 줄이기 |
| 모래 폭풍·과도한 이펙트 | 이펙트 단어 많음 | 1~2개로 축소 + "❌ NO sandstorm" 등 부정 |
| 액션 잘못 해석 (예: 길동 다이브) | 의도 명시 부족 | 익숙한 모션 비유 + ⚠️ CRITICAL 강조 |
| HUD 안 보임 | 명시 없음 | 4가지 HUD 위치별 명시 |
| 캐릭터 외형 깨짐 | 주체 등록 안 함 | 주체 길동 다각도 등록 (1회 등록 후 영구 재사용) |
| 시작 프레임 어긋남 | 다중 레퍼런스 모드 사용 | Start-End Frame 모드로 전환 |
