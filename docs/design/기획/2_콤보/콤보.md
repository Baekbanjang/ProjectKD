## 🌳 콤보 트리 — 6 시퀀스

> **표기**: `L` = LMB(약공) / `H` = RMB 탭 강공 / `Hc` = RMB 0.5s 홀드 차지 강공

| # | 입력 | 역할 | 마무리 효과 |
|---|------|------|-------------|
| 1 | `L → L → L → L` | 약공 4타 풀 콤보 | 마지막 타에 누적 데미지 + 작은 넉백 |
| 2 | `L → L → H` | 3타째 강공 마무리 | **띄우기 시동** (Posture 누적 중) |
| 3 | `L → L → L → H` | 4타째 강공 마무리 | **큰 띄우기 + 폭발** (Posture 큰 누적) |
| 4 | `L → H` | 빠른 캔슬 강공 | Counter Combo (데미지↓·반응속도↑) |
| 5 | `H` | 단발 강공 | 단발 띄우기 시동 |
| 6 | `Hc` | 차지 강공 (0.5s) | **가드 깨기** + Posture 큰 누적 |

> 🔗 강공(2·3·5·6) → 적 부양 → R 동에번쩍 (공중QTE) 연결 가능. 상세 [[기획/5_공중QTE/공중QTE]].
