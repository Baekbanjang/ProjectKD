# docs/design — 기획 문서

게임 디자인 문서 (GDD, 메커닉 정의, 시스템 설계 등). 페어 둘 다 작성·갱신.

## 권장 구성 (필요 시 추가)
- `overview.md` — 컨셉, 코어 루프, 타겟 플레이어
- `combat.md` — 전투 메커닉 (애니, 데미지, 히트스탑, 컴보)
- `enemies.md` — 적 행동 / AI 의도
- `progression.md` — 성장·획득·리워드 시스템
- `controls.md` — 입력 매핑 / 게임패드 / 키보드

## 룰
- 기획 변경이 코드 영향 줄 때 → `docs/specs/`에 결정사항으로 반영
- 추측·미정 사항은 `TODO:` 또는 `?` 마크 명시
- 이미지·다이어그램은 `docs/design/assets/`에 별도 보관
