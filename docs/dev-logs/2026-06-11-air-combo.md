# 공중 콤보 (Air Combo / 공중 속공) — 2026-06-11

## 요청
스텔라 블레이드식 공중 속공. 점프 중 좌클릭 연타 → 공중 1~4타 연속 공격. 공격 동안 체공(낙하 멈춤) 유지, 콤보 끝나면 떨어짐. 나중에 공중 콤보 여러 종류 추가 예정 → 데이터 확장 구조.

## 신규 태그

## 아키텍처 결정
- **체공 = 중력 억제** (A안): `OnActivated`에서 `GravityScale=0` + `Velocity.Z=0` → 그 높이 고정. `OnCleanup`에서 `OrigGravityScale` 복원(모든 종료 경로 수렴, `Super::OnCleanup` 필수).
- **무한 체공 차단 = 4타 캡 + 막타 쿨다운 두 겹**: 디폴트 몽타주 배열 인덱싱은 `FMath::Min(Length-1, Num-1)` (wrap `%Num` 금지). 4타 도달 = 콤보 끝 → `bIsFinisher` → `OnCleanup`에서 `AirComboLockGE`(Duration ~0.6~1.0s) 부여. 캔슬-체이닝만으론 콤보가 "끝"나질 않아 쿨다운이 안 걸리므로 캡이 필수.
- **지상 콤보 트리와 분리**: `GA_PlayerAttackBase`가 ProcessInput으로 지상 트리를 강제로 타서 상속 불가 → OneShot 상속 + 공중 전용 ActivateAbility 오버라이드.
- 중력 제어는 GA→Pawn 캐스팅(`Cast<ACharacter>(GetAvatarActorFromActorInfo())`)이라 §1-3 합법 (컴포넌트 분리하면 오히려 Component→Pawn 위반에 근접).
- GA는 InstancedPerActor → `OrigGravityScale`은 매 `OnActivated`에서 캐시 갱신.

## 입력 분기 (KDPlayerCharacter)
- `TryLightAttack`: 공중(`IsFalling()`)이면 `Ability.Mugong.AirCombo` 활성, 실패 시 InputBuffer Push, return.
- `Tick` 버퍼 소비: 공중이면 AirCombo로 라우팅, 아니면 기존 Light/Heavy.
- `TryConsumeAndActivate` CancelTags에 `Ability_Mugong_AirCombo` 추가.

## 검증 (PIE) — 통과
- 땅 공격=일반 콤보 무변화 / 점프 좌클릭=공중 1타 그 높이 멈춤 / 연타 2→3→4타 체공유지 / 4타 끝 쿨다운+중력복원+낙하 / 캔슬-체이닝으로도 4타에서 끝(무한체공 X) / 피격으로 끊겨도 중력 복원.
